# Audit Summary

**Framework:** React 18 + TypeScript (Vite) frontend, FastAPI (Python) backend, Electron wrapper. **Styling:** Inline styles via centralized `theme.ts` — Robinhood Legend aesthetic (near-black backgrounds, green hero accent, Inter body font + JetBrains Mono for data). No CSS files, no CSS-in-JS libs. **State management:** React Query (`@tanstack/react-query`) for all server state; `useState` for local UI. No Redux/Zustand. **Data layer:** Axios-based API client (`api.ts`) with auth interceptors; backend providers inherit from `BaseProvider` ABC and are chained via `try_providers()` in `fallback.py`. **Widget containers:** `Panel` (simple title + content) and `PanelV3` (draggable, freshness indicator). Shared primitives: `DataGrid` (virtualized, sortable, responsive with stagger animations), `DataTable` (simple sortable), `TickerBadge`, `LoadingBar`, `Sparkline`, `TabBar`. **Function-code routing:** `commandParser.ts` maps uppercase commands → `ScreenType` literal union; `App.tsx` switch-cases render the corresponding Screen component (all screens receive `onNavigate` prop). **Persistence:** SQLite via `database.py` with explicit `init_db()` schema creation; `cache.py` provides TTL-based JSON caching in dedicated tables (price_cache, news_cache, chart_cache, econ_cache, financials_cache). **LLM integration:** Existing pattern in `ai.py` — try Ollama localhost:11434 first, fall back to Claude API via httpx.

**Conflict:** The `MACRO` command already exists, routing to a simple FRED-indicators table view. This is redundant with the existing `ECON`/`ECST` commands. The new MACRO system will **replace** the existing implementation entirely.
